A newspaper front page that sums up **Wednesday 18 November 2026** in one
image — six stories that defined the day:

1. **Iran Closes the Strait** — Iran says a fourth tanker hit a mine;
   ships need its approval.
2. **APEC Opens in Shenzhen** — Xi opens leaders' meeting; Trump, Putin
   due Thursday.
3. **Democrats Take Alaska** — Peltola flips Senate seat; Democrats
   reach 56 seats.
4. **Cyclone Xavier Slams Cooks** — Category 5 storm batters Cook
   Islands; gusts hit 315 km/h.
5. **Outages Reach the NSA** — spy agency's classified network goes
   down; officials deny cyberattack.
6. **19 Die in Siberia Crash** — military transport plane crashes near
   Kemerovo; probe opened.

The page is drawn as `entry.html` (inline CSS + flat-colour inline SVG,
no network) and rendered to `entry.png` (1024×1024) with Playwright's
Chromium; `main.ts` (Node 22, standard library only) copies `entry.png`
to `/output/entry.png`. Running it twice produces byte-identical output.
